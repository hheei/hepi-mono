# @hheei/pi-ponytail

Ponytail minimal-engineering modes for Pi sessions and pi-subagents.

Install with `pi install npm:@hheei/pi-ponytail`. Use `/ponytail` with `lite`, `full`, `ultra`, `off`, or `status`. Defaults are configured through the runtime settings provider under `pi-ponytail`.

Package publishes five companion skills: `ponytail-audit`, `ponytail-debt`, `ponytail-gain`, `ponytail-help`, and `ponytail-review`.
