# @hheei/pi-example

Example Pi extension package for `hepi-mono`.

## Try It

```bash
pi -e packages/pi-extcore/src/extension.ts -e packages/pi-example/src/index.ts
```

Then run:

```text
/pi-example
/extension-setting
```

The package also registers a `pi_example_echo` tool that the model can call.
