# @hheei/pi-ext-tools

Canonical owner for Pi `read`, `edit`, `write`, and `bash` replacements. Install with
`@hheei/pi-ext-core` and `@hheei/pi-loadout`.

This release must be paired with `@hheei/pi-fff` that no longer registers `read`; an older
`pi-fff` conflicts with this package. `pi-fff` continues to own `grep`, `find_files`, and
`fff_multi_grep` during split migration.
