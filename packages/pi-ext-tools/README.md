# @hheei/pi-ext-tools

Canonical owner for Pi `read`, `grep`, `find`, `edit`, `write`, `bash`, and FFF-only
`fff_multi_grep`. Install with `@hheei/pi-ext-core` and `@hheei/pi-loadout`.

FFF runtime, commands, autocomplete, and enhancement settings are included; this package absorbed
the retired standalone FFF extension.
