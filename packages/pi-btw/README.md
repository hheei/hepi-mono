# @hheei/pi-btw

TUI-only side questions through `/btw [question]`. Requires `@hheei/pi-basics` and the active Pi model.

A side question runs without tools and does not modify the main transcript. `/btw` without text opens session history. `Esc` cancels, arrow keys scroll, and `x` clears history.

History is memory-only and discarded at session shutdown. Only one request runs at a time.
