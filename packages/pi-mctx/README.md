# @hheei/pi-mctx

This package is an inactive source baseline copied from
[`cortexkit/magic-context`](https://github.com/cortexkit/magic-context) at
`7dcd2e5726a1466126b2eea460482cca2b53283b`. It declares no Pi extension entry
and is not publishable or loadable until its first HEPI-adapted slice is designed
and verified.

The previous implementation is retained at `packages/xpi-mctx/` for comparison.
