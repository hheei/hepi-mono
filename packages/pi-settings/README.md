# @hheei/pi-settings

Settings-surface host and Loadout policy owner for HEPI Pi extensions. Install it with
`@hheei/pi-ext-core` and settings-provider packages such as `@hheei/pi-ext-tools`.

Run `/ext-settings` or `/loadout` in Pi TUI mode. The package hosts registered settings pages, owns
tool/skill/resource activation policy, and temporarily suspends core-managed editor widgets while the
surface is open.
