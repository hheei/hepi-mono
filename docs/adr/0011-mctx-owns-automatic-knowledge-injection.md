# MCTX owns automatic knowledge injection

When MCTX knowledge integration is enabled, pi-mctx is the sole automatic Hindsight-derived provider-context injector. pi-hindsight continues to own retain, bank/scope policy, queueing, explicit recall, and reflect, but its direct mental-model and per-turn recall injection is suppressed. This supersedes only the automatic-recall-before-provider-context part of pi-hindsight ADR-001: a single injector is required for deterministic context budget and prefix-cache behavior.
